# HarborScout deck source

This folder preserves the content modules and visual QA contact sheet from the original generated draft deck. Read the [artifact status and known QA limitations](../README.md) before reuse.

The `.mjs` files expect a presentation-rendering context supplied by the original private runtime. That renderer, its dependencies, and the private planning source are not part of this repository, so this bundle is reference source rather than a one-command reproducible build.

Use the historical [PDF](../harborscout-ai-yc-investor-pitch-deck.pdf), [PPTX](../harborscout-ai-yc-investor-pitch-deck.pptx), and [contact sheet](qa/contact-sheet.png) to review the result. Assumptions and placeholder company details are identified in `profile-plan.txt`.
