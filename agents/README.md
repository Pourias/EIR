# Specialist roles

EIR can run as one agent. When parallel agents are available, these three bounded roles improve coverage without splitting final accountability.

| Role | Owns | Must not do |
|---|---|---|
| [Scout](scout.md) | Source discovery, source classes, freshness, and coverage gaps | Write the investment verdict |
| [Analyst](analyst.md) | Product, market, economics, distribution, and synthesis | Hide missing evidence behind confident prose |
| [Skeptic](skeptic.md) | Contradictions, failure modes, alternatives, and kill questions | Reject a thesis without evidence or a test |

The root EIR agent integrates their work, opens the consequential sources, resolves conflicts, and owns the final verdict.

Historical manifests may mention other private-runner roles or skills. Those names are provenance, not bundled dependencies.
